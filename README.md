# MA AJAB TOURS AND SAFARIS

A static website for MA AJAB TOURS AND SAFARIS, a travel agency based in Watamu, Kenya. The site showcases safari packages, local excursions, services, and contact details for travelers planning trips across Kenya.

## Project structure

- `index.html` – Home page with hero section, introduction, and service highlights
- `safaris.html` – Safari packages and wildlife experiences
- `excursions.html` – Day trips and coastal excursion options
- `services.html` – Transfer, accommodation, and travel support services
- `about.html` – Company story, mission, and experience overview
- `contact.html` – Contact and booking information
- `css/style.css` – Styling for the website
- `js/main.js` – Interactive behavior for navigation and page effects

## Features

- Responsive navigation with desktop and mobile menu support
- SEO-friendly metadata and social sharing tags
- Clean visuals for safari and travel marketing
- Simple static website suitable for GitHub Pages or any static host

## Deployment

The site can be deployed as a static website directly from this repository. Common options:

- GitHub Pages
- Netlify
- Vercel
- Any static web host

## Notes

- `.gitignore` is configured to ignore `.vscode/` and common OS/editor artifacts.
- No build step is required; the website is ready to serve as static HTML/CSS/JS.
